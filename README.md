# 能量核心（flightcore）

Minecraft **1.21.1** / **NeoForge 21.1.253** 的自研 FE（Forge Energy）能源与飞行饰品模组。

包含：飞行饰品、FE 发电/储电/输电、物品充电、化工材料链（橡胶/乙烯/塑料/外壳/核心），并与 Jade、JEI 做了集成。

---

## 依赖

| 类型 | 模组 | 版本 |
|---|---|---|
| 必需 | Minecraft | 1.21.1 |
| 必需 | NeoForge | ≥ 21.1.248（开发基线 21.1.253） |
| 必需 | Curios | ≥ 9.5.1（飞行核心占用独立饰品槽） |
| 可选 | Jade | ≥ 15（悬浮显示机器/电网信息） |
| 可选 | JEI | ≥ 19（显示机器加工配方） |

## 内容

### 饰品 / 物品
| 物品 | 说明 |
|---|---|
| **飞行核心** | 占用 Curios 独立槽（`flycore`）；穿戴即获得飞行，飞行时每 tick 消耗 50 FE；容量 1,200,000 FE（满电 20 分钟）；飞行速度 `0.03`（原版 0.05） |
| **随身电池** | 600,000 FE / 输出 2,400 FE/t；放在背包里自动给身上（饰品/护甲/手持）的 FE 装备供电 |
| **橡胶 / 乙烯 / 塑料** | 化工材料链 |
| **机器外壳 / 机械核心** | 进阶设备的合成件 |

### 机器 / 方块
| 方块 | 参数 |
|---|---|
| **FE 发电机** | 288 FE/t；**1 煤 = 65 tick（≈3.25 秒）**；缓冲 100,000 FE；主动向相邻方块供电 |
| **FE 充电器** | 充能 1,200 FE/t；缓冲 30,000；吸收掉在上方的可充电物品；**拆掉会掉落内部物品** |
| **蓄电池模块** | 200,000 FE/块；进出 1,200 FE/t；相邻模块自动均衡 |
| **蓄电池管理模块** | 统计整组电量/容量/输入/输出功率/模块数（Jade 悬浮查看） |
| **橡胶制作器** | 甘蔗×2 + 2,000 FE → 40 tick → 橡胶×1 + 乙烯×1 |
| **塑料制作器** | 橡胶×2 + 乙烯×1 + 8,000 FE → 60 tick → 塑料×2 |
| **电线（铁/铜/金）** | 1,200 / 6,000 / 30,000 FE/t；**逐段限流**；细管外观、六向自动连接 |

### 关键机制
- **电线不存电**：纯导体，按"电源端 → 负载端"直送，每段按自身额定载流量限流（金线干线可带多条铁线支路）
- **供需诊断**：Jade 显示「需求 X FE/s ｜ 实际 Y FE/s」，供电不足会标红
- **空中挖掘**：原版飞行时挖掘速度 ÷5；本模组通过 Mixin 在"由飞行核心提供飞行"时抵消该惩罚
- **掉落保护**：拆掉机器会把内部物品掉出来

## 合成 / 加工链

```
甘蔗 ──[橡胶制作器]──> 橡胶 + 乙烯
                        │
橡胶 + 乙烯 ──[塑料制作器]──> 塑料
                                │
塑料×4 + 铁×4 ──> 机器外壳 ──┬──> 蓄电池模块（铜4+金4+外壳）
                              └──> 机械核心（外壳+蓄电池模块+金6）
                                      ├──> 蓄电池管理模块
                                      ├──> 随身电池
                                      └──> 飞行核心

电线（铁/铜/金）= 金属×3 + 橡胶×1 → 8 根
```

> 发电机 / 充电器保持基础配方（铁+红石+熔炉 / 铁+铜+末影珍珠），避免"要塑料才能发电、要发电才能做塑料"的死循环。

## 构建

```bash
# 1) 把运行期依赖的 API jar 放进 libs/
mkdir -p libs
cp <你的mods目录>/curios-neoforge-9.5.1+1.21.1.jar libs/
cp <你的mods目录>/Jade-1.21.1-NeoForge-15.10.6.jar libs/Jade-1.21.1-NeoForge-15.10.6-api.jar
cp <你的mods目录>/jei-1.21.1-neoforge-19.57.0.451.jar libs/jei-1.21.1-neoforge-19.57.0.451-api.jar

# 2) 构建（需 Java 21）
./gradlew build
# 产物：build/libs/flightcore-<version>.jar
```
